# Prepared videos

Самодостаточный набор материалов для проверки результатов `clipmaker-lite` по
тикету `PROMOPAGES-9910`.

В корне находятся 20 папок статей. Структура каждой папки:

```text
<article-slug>/
├── article-content.json
├── images/
│   └── все изображения статьи в исходном порядке и формате
└── Generated video 1/
    ├── 01.<исходное расширение>
    ├── wan-2.2/
    │   ├── prompt.json
    │   └── video.mp4
    ├── wan-2.7/
    │   ├── prompt.json
    │   └── video.mp4
    └── veo-3.1-lite/
        ├── prompt.json
        └── video.mp4
```

- `article-content.json` — точная копия полного структурированного контента
  статьи: заголовок, лид, текстовые блоки, ссылки, CTA и позиции изображений.
- `images/` содержит все 125 изображений из статей, включая намеренно
  повторяющиеся cover/body-файлы; изображения не дедуплицировались и не
  конвертировались.
- `Generated video 1/` соответствует первой фотографии статьи, использованной
  для текущего набора генераций. Её точная копия лежит непосредственно в этой
  директории.
- В каждой модельной поддиректории `prompt.json` лежит рядом с созданным по нему
  `video.mp4`. Помимо positive/negative prompt в receipt сохранены structured
  intent, runtime-параметры и provenance.
- Всего набор содержит 60 выбранных результатов: 20 статей по три модели.

Соответствие файлов взято из корневого `manifest.json`. Для Wan 2.2 выбраны две
успешные primary-генерации и 18 результатов `wan-legacy-retry5`; диагностические
named-route дубли не включены. `dataset-manifest.json` фиксирует источники и
контрольные суммы контента и изображений.

Итоговая проверка комплекта проходит с `allow_contract_warnings: true`. У Wan
2.7 сохранены известные предупреждения по медиаконтракту исходных результатов;
это единственные доступные выбранные Wan 2.7-файлы, а не retry-дубли.
